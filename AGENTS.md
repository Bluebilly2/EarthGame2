# AGENTS.md — EarthGame2

The house rules for any agent working here are in **[`CLAUDE.md`](CLAUDE.md)**, and they are the same rules
whichever model is at the keyboard. Read that file; this one holds no rules of its own.

It is a pointer rather than a copy because the first rule it states is that a fact lives in one place: two rule
files with nothing forcing them to agree would drift apart within a week, and the one an agent happened to read
would decide how it worked. `CLAUDE.md` is the name Claude Code loads automatically and `AGENTS.md` the name
Codex and others look for, so the pointer exists to serve both without splitting the rules.
