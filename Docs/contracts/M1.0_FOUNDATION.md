## What this slice promises

1. A repository at `C:\Users\willi\projects\EarthGame2` with the layout `Engine/`, `Unity/`, `Tools/`, `Data/`,
   `Docs/`, pushed to the private GitHub repository `Bluebilly2/EarthGame2`, with the pre-push hook active.
2. The five engine-free packages (`Engine`, `Protocol`, `Transport`, `Server`, `ClientCore`) as local UPM packages,
   compiled by both dotnet and Unity from the same files, with a headless test suite that passes.
3. **There is no single player, proven:** a `GameServer` and a `GameClient` in one process complete the handshake
   over `InMemoryTransport` and over a real UDP loopback, including under the transport's loss/latency simulator;
   a refusal crosses the wire with its reason; a dedicated console host runs the same server.
4. A Unity 6000.3 project with URP Forward+, the settings checklist applied and asserted by an edit-mode test, the
   local packages referenced, the template's sample content removed, and a Bootstrap that runs SOLO (in-memory)
   and can host and join over UDP loopback — ticking an empty world, drawing nothing yet.
5. The compile check of the Unity assemblies from dotnet (`Engine/EarthGame.Unity.Compile.csproj`).
6. The governing documents: `CANON.md`, `ARCHITECTURE.md`, `STANDARDS.md`, `DEBTS.md`, `CLAUDE.md`,
   `THIRD_PARTY_NOTICES.md`, this contract; the constitution and binding v1 docs carried verbatim.
7. The verifier-lane machinery: `Tools/verifiers/MANIFEST.json`, the gate runner, the pre-push authorship rule —
   with the missing-verifier refusal demonstrated.
8. `Tools/data/fetch_tiles.py` and `bake_region.py` v0 for the Bherwerre box, so the owner's verifiers have
   something to check.
9. A first player build via a batch-mode build entry point, muted and windowless when automated.

## Error budget and non-goals

No world content, no terrain, no rendering beyond an empty scene. Frame-rate and netcode numbers are not claimed
here; they are M1.A's and M1.B's. The UI Toolkit tablet spike is a one-day timebox that proves a scrolling page
renders, nothing more.
