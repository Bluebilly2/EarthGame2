# BF.7 part one: the downloads (ruling 49)

The record CANON 49 asks for, of every file the research for BF.7 part one fetched and kept (a cloud session,
2026-09-25): its source, its size, its SHA-256 and its licence as the file or its page states it. The contract,
`BF.7_THE_BODYS_REST.md`, names the files the code's numbers came from; this is the whole of it.

- **What they are.** Papers, reports, theses, tables, web pages, and abstracts from the Europe PMC and NCBI
  E-utilities interfaces: read as text (`pdftotext`, a Python strip of the HTML, the XML as it came) or looked at as
  images, and never run. They are kept in the session's scratch space, not in the repository: nothing is vendored,
  so none wants a line in `THIRD_PARTY_NOTICES.md`. What reached the code is numbers, each cited where it is used.
- **Fetching one again.** `curl -L -o <file> '<source>'`. An E-utilities source is
  `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pubmed&id=<ids>&rettype=abstract&retmode=text` for
  abstracts and `...efetch.fcgi?db=pmc&id=<PMC digits>&retmode=xml` for a full text. A live page may have changed
  since; the hash is of the copy read, recomputed from the file when this record was written.
- **Not listed.** Refused downloads (403, 404, 429, challenge and CAPTCHA pages), which were discarded; pages read
  through the session's fetch tool and abstracts read from an interface's reply without a file being kept, whose
  sources are cited where their numbers are used; and one Europe PMC reply fetched under a wrong identifier (PubMed
  9794077, 3,953 bytes, a paper on jojoba) and deleted unread.
- **Licences.** As stated in the file or on its page, and "not stated" where neither says; the research's own
  reading, not a lawyer's. Several copies are of articles whose publishers keep their rights: read here, cited, and
  not copied into the repository.
