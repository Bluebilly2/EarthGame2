# Standards — the laws of code and proof, dated, with their failure stories

**Status (owner ruling 15, 2026-09-07):** every standard here is a dated ruling like any other and is demotable by
the same process: when a standard's enforcement cost exceeds its failure story, it is demoted with a dated entry
in the log at the end of this file, never silently ignored. This file does not become a conductor: it holds the
rules that have earned their place by a failure someone paid for, and each row says how it is enforced.
"Review only" is honest; a rule broken twice on review gets a mechanical enforcement or a demotion.

| # | Since | Standard | Failure story | Enforced by |
|---|---|---|---|---|
| 1 | 2026-09-07 | **Layering.** Engine-free packages never import `UnityEngine` and contain no `#if`; the client never references the server and vice versa; only Bootstrap knows both. | v1's Sim stayed clean for the whole project while every player-reachable bug lived in the layer nothing compiled headlessly. Rust pays a permanent tax for `#if SERVER` sprinkled through gameplay code. | compile: asmdef `noEngineReferences`, the dotnet build of the same files; a source scan for `#if` and `UnityEngine` in engine-free packages (M1.0) |
| 2 | 2026-09-07 | **One owner per fact.** A fact about the world lives in one place; finding a second copy obliges you to alias or delete it in the same commit. The tablet quotes the models the world runs, never a second derivation. | v1 counted eighteen copies of `Clamp01`, seventeen agreeing and wrong; its worst visual bug was two owners of "the brightest directional light". | review; targeted source scans where a second copy has already appeared once |
| 3 | 2026-09-07 | **Determinism.** Nothing in the engine reads wall-clock time, environment state or an unseeded random source; the digest budget is twelve significant figures. | v1's determinism tests are what made saves, gates and reproduction possible at all. | test: `SimDeterminismTests`; a source scan for `DateTime.Now`, `Environment.TickCount`, `System.Random`, `Guid.NewGuid` in engine-free packages |
| 4 | 2026-09-07 | **Save law.** Additive fields with initialisers, never a version bump for what an initialiser fixes; every persisted field enters the digest in the same commit; one writer (the server), atomic replace. | v1 shipped four save fields missing from the digest, and a pre-fix save that deleted the file before writing the new one. | test: a reflection test that every persisted field is in the digest; review |
| 5 | 2026-09-07 | **Input seam.** Every key and mouse read the game makes goes through one seam a scenario can drive; a new verb ships with a scenario step that presses it. "Reachable by a player" is proven by a script pressing the real buttons. | v1's twenty keys; verbs that compiled and were unreachable. | scenario corpus (from M1.A); source scan that no gameplay file reads input directly |
| 6 | 2026-09-07 | **Test law per change type.** Engine behaviour → a headless test that fails without the change. Unity behaviour → compiles and a scenario reaches it. Visual → frames at 1440p and 1080p or the owner's eyes. Feel → the owner's hands (ruling 12). A claimed removal → a source-text assertion of absence. A save-format change → digest coverage and a round trip. | v1: "six bugs only running found"; the feel review; the fabricated verdict. | review at merge; the gate runner |
| 7 | 2026-09-07 | **A test names the guarantee, not the mechanism**; no test that cannot fail; enforcement tests are proven by sabotage before they are trusted. | v1 shipped three vacuous guards on one seam and a regex that matched everything. | review: every new enforcement test's commit shows the sabotage red |
| 8 | 2026-09-07 | **A gate that cannot run fails loudly.** Never pipe a suite into `tail` or `head`; redirect, echo the exit code, then show the log. A missing owner verifier is a red, never a skip. | 2026-09-08: this project's own first build looked green because `dotnet build \| tail` reported `tail`'s exit code; four tests were red underneath. | `Tools/gate/run_gate.py`; the pre-push hook; review |
| 9 | 2026-09-07 | **The verifier lane** (ruling 16). Claude writes the tools; the owner writes the checks under `Tools/verifiers/owner/`; Claude never writes one to unblock a gate; a stalled lane is surfaced, not bypassed. | v1's fabricated verdict: one party authored both the tool and its check. | pre-push hook rejects Claude-co-authored commits touching the owner's lane; the gate runner |
| 10 | 2026-09-07 | **Contracted formats.** Every format an owner verifier reads carries a version field and is recorded in `ARCHITECTURE.md` §10; a schema change is a renegotiation in writing. | Verifiers that chase a moving format get "fixed" to pass. | review; the format table |
| 11 | 2026-09-07 | **Date the ruling, never the state.** A comment may cite a decision and its date; it must not assert a count, a copy-number or another fact about the tree that will drift. Doc comments explain mechanism and history and sit directly above what they document. | v1's comments carried counts that went false within hours; its best comments prevented their bug's recurrence. | review |
| 12 | 2026-09-07 | **No TODO comments.** A debt goes into `DEBTS.md` with an owner and a pay-by. | v1's debts lived in five places and rotted. | source scan for `TODO`/`FIXME`/`HACK` in the tree |
| 13 | 2026-09-07 | **A doc that contradicts code is amended in the same commit.** `ARCHITECTURE.md` is a claim about the tree. | v1's coordinate doc mandated a sphere for two weeks after the game went flat; nobody amended it. | review |
| 14 | 2026-09-07 | **Automated runs are isolated, muted and off the owner's screen.** A visible window exists only when the owner asks to watch or play. | v1's instances made noise over the owner's film and opened windows on his monitor. | the launcher (from M1.A) |
| 15 | 2026-09-07 | **Frames or it did not happen** for visual claims; **hands or it did not happen** for feel claims. The renderer's state is logged beside every captured frame. | The v1 fix that was "indistinguishable from the baseline" until the rig line was logged beside the frame. | the recorder (from M1.A) |
| 16 | 2026-09-07 | **Third-party notices in the same commit.** Every vendored file, asset or dataset lands with its licence and attribution entry. | Attribution obligations are easy to forget and expensive to reconstruct. | review |
| 17 | 2026-09-08 | **A generated knowledge graph is a map, never a source of truth.** If a graph of the repo is ever generated (for example with Graphify's Obsidian export), it is build output: ignored by git, never cited in a ruling, never hand-edited. `CANON.md` is the only record of what the owner decided. | v1 lost track of whose rulings were whose in a 15,000-line generated record. | `.gitignore`; review |
| 18 | 2026-09-08 | **Commit messages claim exactly what the commit contains**; a test count is stated only when it was run in that commit's tree. | v1 stated counts from memory and they drifted. | review |
