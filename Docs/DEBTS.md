# Debts

Known, owned, dated. A debt is recorded here the moment it exists; there are no TODO comments in code. An entry
leaves this file only by being paid (with the commit that paid it) or by an owner ruling that retires it.

their own table because they were the one class of debt this register never held: on 2026-09-20 a reading of the

not one of these — twenty contracts said "his eyes" or "his hands" were owed, nothing listed them together, and
questions asked once died unasked again. A row leaves by his word, and the slice that raised it keeps the detail.
